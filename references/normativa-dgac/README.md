# Referencias Normativas DGAC — Material de Desarrollo

> **AVISO IMPORTANTE**: Esta carpeta contiene material de referencia exclusivamente para el desarrollo de VantOPS Chile. No constituye normativa vigente ni sustituye la consulta directa a la fuente oficial.

## Fuente oficial

La autoridad de referencia es la Dirección General de Aeronáutica Civil (DGAC) de Chile.

**URL oficial:** https://www.dgac.gob.cl/normativa/reglamentacion-aeronautica/normas-dan-nueva/

## Reglas de uso

1. La fuente oficial DGAC es la autoridad de referencia.
2. Los PDF almacenados localmente son material de consulta para desarrollo.
3. Nunca asumir que un PDF local representa la versión vigente.
4. Antes de implementar una funcionalidad normativa:
   - Verificar la versión vigente en DGAC.
   - Distinguir documentos vigentes, históricos, borradores/opiniones.
   - Registrar la referencia utilizada.
   - No convertir interpretación normativa en autorización automática.
5. VantOPS **informa**. La autoridad aeronáutica **determina**.
