# Identidad visual — VantOPS Chile

**Marca elegida:** B1 · Vector V Andino. Este directorio contiene la selección **ligera y pública** de recursos visuales de la marca. Los packs maestros para web, redes, APK y comunicaciones permanecen como archivos de diseño externos; **no deben copiarse completos** dentro del bundle PWA.

## Identidad canónica

- **V:** monograma de VantOPS; navegación y operación.
- **Cordillera:** señal geográfica discreta del territorio chileno.
- **Trayectoria cian:** ruta de planificación y navegación.
- **Pin:** ubicación y georreferencia.
- Paleta principal: fondo `#071827`; superficie `#0D273D`; acento `#00D4FF` (según contraste); texto `#F5F9FF`; advertencia `#F0A446`.
- Asegurar contraste AA en texto y estados. **No usar el color como único indicador**.

## Uso recomendado

**README/portfolio:** el banner y el icono B1 anteriores. **Aplicación web/PWA:** icono optimizado para favicon/manifest; integrar desde la carpeta `public/` solo después de verificar que los PNG adecuados realmente fueron actualizados. **Android:** usar capas adaptive-icon y monochrome del kit; la futura APK **aún no está publicada**.

El gráfico de marca no significa aprobación, permiso, certificación ni vinculación con la autoridad aeronáutica. VantOPS es una herramienta independiente de apoyo RPAS.

## Precauciones

No importar al proyecto las plantillas promocionales, fotografías, fondos pesados, renders o el megazip completo. Versionar solo los recursos finales que utiliza el producto, con nombre estable, peso reducido y licencia clara. Evitar utilizar capturas simuladas como evidencia del producto en producción.
